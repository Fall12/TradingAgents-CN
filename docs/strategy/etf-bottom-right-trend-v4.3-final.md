本文档为策略设计冻结稿。后续不再增删因子、不改变核心定位；仅允许工程实现、数据与回测代码层面的修正。

## 0. 核心定位（不可变）

用少量可解释因子捕捉 ETF「底部右侧启动」，通过环境仓位控制与趋势退出，让收益来自中期趋势，而不是预测顶部。

| 捕捉 | 放弃 |
| --- | --- |
| 阶段调整 → 风险释放 → 资金重新进入 → 趋势启动初期 | 长期熊市抄底 |
| | 高位趋势追涨 |
| | 超短线爆发行情 |

| 属性 | 定义 |
| --- | --- |
| 策略类型 | 中短周期趋势跟随 · 右侧确认型 · ETF 轮动增强 |
| 持仓周期（预期） | 20～120 个交易日 |

## 2. 工程约定（一致性修正）

以下约定消除实现歧义，**不改变策略框架**。

### 2.1 区间边界

除特别说明外，评分分档采用 **左闭右开** `[a, b)`；最高档单独注明。

### 2.2 历史高点 / 位置系数（不含当日）

与突破定义统一：

```
High_N(t) = max(Close[t-N : t-1])   # 不包含当天 t
Position(t) = Close[t] / High_120(t)
```

因此创新高时 `Position > 1`，可落入「>1.00 → 4 分」档；若误用含当日最高价，则 `Position ≤ 1` 恒成立，该档失效。

「突破 N 日高点」= `Close[t] > High_N(t)`。

### 2.3 突破确认

| 周期 | 确认规则 |
| --- | --- |
| 20 日 | 当日收盘突破即可 |
| 60 / 120 日 | 连续两个交易日收盘站上对应高点 |

### 2.4 趋势突破得分（取档，不叠加）

按已确认的最高档取分，**不累加** 20/60/120：

| 条件 | 分数 |
| --- | ---: |
| 无 20 日突破 | 0 |
| 突破 20 日高点 | 8 |
| 突破 60 日高点 | 16 |
| 突破 120 日高点 | 20 |

额外条件（可叠加，总分封顶 20）：

```
Close > MA20  且  MA5 > MA10  → +2
```

### 2.5 评分计算顺序

```
1. 六大模块原始分求和（满分 100）
2. 应用扣分（累计最多 -20）
3. FinalScore = max(0, min(100, 原始分 + 扣分))
4. 「一日游」：昨日用已落库 FinalScore；今日用当日模块合计（扣分前），避免循环依赖
```

### 2.6 市场状态判定优先级

每日先按优先级匹配，**先命中先生效**；状态切换另需连续 3 日确认（确认期内沿用旧状态系数）。

```
1. Bull
2. Bear
3. Recovery
4. Neutral（需满足近均线 / 均线收敛条件）
5. 否则保持上一确认状态；若无历史状态，按 Neutral 系数执行
```

### 2.7 退出规则优先级（同日多条件时）

```
1. 账户级熔断减仓
2. 初始 ATR 止损（全平）
3. 极端止盈（全平）
4. 时间止损（全平）
5. 二级止盈 / 均线止损（跌破 MA20 且次日未收回 → 全平）
6. 一级止盈（跌破 MA10 → 减仓 50%）
```

「跌破 MA20」的均线止损与二级止盈合并为同一退出路径。

### 2.8 仓位与成交默认

- 文中百分比均为相对账户净值  
- 稳健基础仓位默认 **10%**（允许区间 8%～12%，敏感性在回测做）  
- 信号日收盘确认，**下一交易日开盘价**成交；涨跌停无法成交则取消该信号  

### 2.9 相对强度线实现

```
RS[t] = Close_ETF[t] / Close_HS300[t]
```

对过去 5 日 `RS` 线性回归，斜率 `> 0` → +4。  
（与「累计收益曲线之比」在固定基期下斜率符号等价，实现统一用价格比。）

## 3. ETF 候选池

每日交易前重建。须同时满足：

### 3.1 上市时间

上市时间 ≥ 1 年（上市不足 1 年直接剔除；指标计算另需足够历史窗口）。

### 3.2 流动性

过去 20 个交易日：日均成交额 ≥ 5000 万元。

### 3.3 剔除类型

货币 / 债券 / 商品 / 杠杆 / 反向 ETF。

主题映射表人工维护，用于同主题仓位限制（§12.3）。

## 5. 趋势位置（20 分）

### 5.1 位置系数

见 **§2.2**：`Position = Close / High_120`（不含当日）。

### 5.2 长周期过滤（二选一即通过）

**条件 A**：`Close > MA250`  

**条件 B**：过去 10 个交易日，`MA60[t] > MA60[t-1]` 的天数 ≥ 8  

### 5.3 基础分

| 位置系数 | 基础分 |
| --- | ---: |
| [0.70, 0.85) | 20 |
| [0.85, 0.95) | 14 |
| [0.95, 1.00] | 6 |
| < 0.70 | 5 |
| > 1.00 | 4 |

不禁止创新高；创新高不属于「底部启动」，评分自然降低。

### 5.4 长周期过滤调整

不满足 5.2：`得分 = floor(基础分 × 0.5)`；满足则 = 基础分。  

买入硬条件「通过长周期过滤」指满足 5.2（与半分评分解耦）。

## 7. 相对强度（20 分）

基准：沪深 300（指数或对应 ETF，全样本保持一致）。

### 7.1 20 日超额收益（最高 16）

```
Excess_20 = ETF_Return_20 - HS300_Return_20
```

| 超额收益 | 分 |
| --- | ---: |
| < 0 | 0 |
| [0, 3%) | 6 |
| [3%, 6%) | 12 |
| ≥ 6% | 16 |

### 7.2 强度趋势（+4）

见 **§2.9**。

## 8. 量价健康度（15 分）

### 8.1 涨跌量比（10 分）· 10 日

```
UpDownVolRatio = mean(Vol | 上涨日) / mean(Vol | 下跌日)
```

上涨：`Close > 昨收`；下跌：`Close < 昨收`；平盘不计。分母为 0 → 本项 0 分。

| 比例 | 分 |
| --- | ---: |
| < 0.8 | 0 |
| [0.8, 1.0) | 4 |
| [1.0, 1.2) | 7 |
| ≥ 1.2 | 10 |

### 8.2 价格效率（5 分）

```
Efficiency = Return_10 / ATR%_10
ATR%_10 = mean(ATR14 / Close) over 10 days
```

`Return_10` 带符号（下跌为负 → 最低档）。

| 效率 | 分 |
| --- | ---: |
| > 0.8 | 5 |
| [0.3, 0.8] | 3 |
| < 0.3 | 0 |

## 9. 量能结构（15 分）

### 9.1 量能趋势（12 分）

```
VolTrend = MA(Volume, 5) / MA(Volume, 60)
```

| 比例 | 分 |
| --- | ---: |
| < 1 | 0 |
| [1, 1.15) | 4 |
| [1.15, 1.3) | 8 |
| ≥ 1.3 | 12 |

### 9.2 连续放量（3 分）

自当日起连续 `Volume > MA(Volume, 20)` 的天数，每天 +1，最多 3。

| < 2% | 10 |

## 11. 扣分机制（最高扣 20）

三项累加后截断为最多 -20。

### 11.1 高位加速（最多 -8）

`Return_20 > 20%` 时：

```
扣分 = -2 × floor((Return_20 - 20%) / 3%)
最低 -8
```

### 11.2 爆量滞涨（-6）

```
量比 = Volume / MA(Volume, 20)
量比 > 2  且  |当日涨跌幅| < 1%  → -6
```

### 11.3 一日游（-6）

```
昨日 FinalScore ≥ 70  且  今日模块合计（扣分前） < 50  → -6
```

## 12. 买入规则

### 12.1 模式 A：稳健型（主策略）

连续两个交易日：`FinalScore ≥ 75` 且通过 §5.2。  
基础仓位：8%～12%（默认 **10%**）。

### 12.2 模式 B：进攻型（辅助）

同时满足：

```
FinalScore ≥ 90
已确认突破 60 日高点
VolTrend > 1.3
Excess_20 > 3%
Position ≤ 0.95
```

仓位：`模式A基础仓位 × 50%`，且单 ETF ≤ 5%；进攻仓合计 ≤ 30% 净值。

### 12.3 组合约束

- 最多同时持仓 **5** 只  
- 按 `FinalScore` 从高到低分配；触上限则不再开更低分标的  
- 同一主题合计仓位 ≤ **25%**

## 13. 市场环境模型

基准：沪深 300。切换须连续 3 日确认。

| 状态 | 条件 | 系数 |
| --- | --- | ---: |
| Bull | Close > MA250 且 MA60 > MA120 且 MA60 向上 | 100% |
| Recovery | Close > MA60 且 Close ≤ MA250 且 MA60 向上 | 50% |
| Bear | Close < MA250 且 MA60 < MA120 | 20% |
| Neutral | 非上三者，且（\|Close−MA250\|/MA250 ≤ 5% 或 \|MA60−MA120\|/MA120 < 2%） | 30% |

优先级见 **§2.6**。`MA60 向上` := `MA60[t] > MA60[t-1]`。

---

## 14. 最终仓位公式

```
最终仓位 = min(基础仓位 × 市场系数, 当前状态单 ETF 上限)
```

另受总仓位上限、同主题上限、进攻仓合计上限约束。

| 状态 | 单 ETF | 总仓位 | 系数 |
| --- | ---: | ---: | ---: |
| Bull | 20% | 80% | 100% |
| Recovery | 12% | 50% | 50% |
| Neutral | 10% | 40% | 30% |
| Bear | 5% | 15% | 20% |

稳健默认基础 10% 时：Bull 10% / Recovery 5% / Neutral 3% / Bear 2%。

## 15. 止损系统

### 15.1 初始 ATR 止损（固定）

买入日锁定，之后 ATR 不更新：

```
止损价 = 买入价 - 2.5 × ATR14（买入日）
```

回测默认：收盘价 ≤ 止损价 → 下一交易日开盘卖出。

### 15.2 均线止损（= 二级止盈）

收盘跌破 MA20，且下一交易日收盘仍未收回 → 全部卖出。

---

## 16. 止盈系统

| 级别 | 条件 | 动作 |
| --- | --- | --- |
| 一级 | 收盘跌破 MA10 | 卖出剩余仓位 50%（每笔持仓仅一次） |
| 二级 | 同 §15.2 | 全平 |
| 极端 | 累计收益 > 30% 且量比 > 2 且当日涨幅 < 1% | 全平 |

---

## 17. 时间止损

买入日 = T+0；第 **20** 个交易日收盘后检查：若期间所有收盘价均 `< 买入价 × 1.1`，则下一交易日全平。

---

## 18. 账户级熔断

| 条件 | 动作 |
| --- | --- |
| 周回撤 > 8%（相对近 5 日净值高点） | 总仓位降至 20%；暂停新开仓 10 交易日 |
| 月回撤 > 15%（相对近 21 日净值高点） | 同上 |

**恢复**：净值回撤 ≤ 5%（相对历史高点）后，解除仓位上限与开仓暂停（恢复条件可提前结束暂停）。

## 21. 策略失效场景

1. 长期横盘震荡  
2. V 型快速反转  
3. 系统性连续暴跌
